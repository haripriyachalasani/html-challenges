Add a table to your HTML page

In HTML, you can create a table using the <table> tag. The table is made up of rows and columns. The rows are created using the <tr> tag, and the columns are created using the <td> tag.

Example of a Table:

Name Age City
John 25 New York
Jane 30 Los Angeles
Doe 22 Chicago
