Creating all the lists in HTML:

In html there are mainly 3 types of lists. They are:

1. Ordered List
2. Unordered List
3. Description List

1. Ordered List:

Ordered list is a list in which the items are in a specific order. It is created using the <ol> tag. The items in the list are created using the <li> tag.

Fruits as an Example

  1. Apple
  2. Banana
  3. Cherry

2. Unordered List:

Unordered list is a list in which the items are not in any specific order. It is created using the <ul> tag. The items in the list are created using the <li> tag.

Vegetables as an Example

  • Carrot
  • Broccoli
  • Spinach

3. Description List:

Description list is a list in which the items are in a specific order. It is created using the <dl> tag. The items in the list are created using the <dt> tag for the term and the <dd> tag for the description.
